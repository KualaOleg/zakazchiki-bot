# Бот вакансий: круглосуточно в GitHub Actions

Бот работает цепочкой: один запуск 5 часов подряд раз в 30 минут вызывает `watch_channels.py`, сохраняет
результат и в конце сам запускает следующий круг. Расписание раз в 2 часа только поднимает цепочку,
если она оборвалась. Одновременно работает не больше одного круга.

Остановить: `gh workflow disable watch-channels` (или Actions → watch-channels → Disable workflow).
Запустить заново: `gh workflow enable watch-channels` и `gh workflow run watch-channels`.

Каждая проверка запускает `watch_channels.py`. Скрипт читает свежую страницу публичных каналов
из `config.json`, отбирает посты по брифу и присылает новые в Telegram.

Отбор:
- роль: SMM, контент-маркетолог, продюсер, редактор / автор текстов, копирайтер, сценарист;
- отсев: тестовое задание, анкета или Google-форма, «этапы отбора», работа в офисе или гибрид
  («без офиса» не считается), резюме и самопиар, реклама и новости, закрытые вакансии;
- бюджет: нижняя граница от `min_budget` — «Подходит»; от `floor_budget` до `min_budget` — «Уточнить»;
  ниже `floor_budget` — отсев; не указан или указан только потолок — «Уточнить»;
- только посты не старше `max_age_hours`.

Тип заказчика (приоритет клиента — частные и малый бизнес, а не штат):
- ⭐ частный: психолог, юрист, предприниматель, эксперт/блогер, малый и средний бизнес (салоны, клиники, студии, кафе);
- проект / фриланс;
- компания (в том числе агентства и продакшены, даже если работают с экспертами);
- штатная вакансия: ТК РФ, оклад, полная занятость, 5/2, ДМС, испытательный срок. Такие уходят только на сайт,
  в Telegram не отправляются, на сайте скрыты по умолчанию (кнопка «Показать штатные»).

`expert_channels` — каналы-биржи, где эксперты сами ищут продюсера или специалиста (например @tinder_tm).
Из них берутся только посты с указанным тегом (`#эксперт`), без проверки бюджета: условия у экспертов
обсуждаются, поэтому такие посты приходят с пометкой «Уточнить».

Фильтр работает по ключевым словам, поэтому ошибается в обе стороны. Настройки — в `config.json`.

## Секреты репозитория

`TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID` из `..\.env`:

    gh secret set -f ..\.env

## Проверка локально

    pip install -r requirements.txt
    python watch_channels.py --dry-run

## Ручной запуск в облаке

    gh workflow run watch-channels
