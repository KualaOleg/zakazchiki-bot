# Бот вакансий: круглосуточно в GitHub Actions

Каждые 30 минут GitHub запускает `watch_channels.py`. Скрипт читает свежую страницу публичных каналов
из `config.json`, отбирает посты по брифу и присылает новые в Telegram.

Отбор:
- роль: SMM, контент-маркетолог, продюсер, редактор / автор текстов, копирайтер, сценарист;
- отсев: тестовое задание, анкета или Google-форма, «этапы отбора», резюме, закрытые вакансии;
- бюджет: нижняя граница от `min_budget` — «Подходит»; от `floor_budget` до `min_budget` — «Уточнить»;
  ниже `floor_budget` — отсев; не указан или указан только потолок — «Уточнить»;
- только посты не старше `max_age_hours`.

Фильтр работает по ключевым словам, поэтому ошибается в обе стороны. Настройки — в `config.json`.

## Секреты репозитория

`TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID` из `..\.env`:

    gh secret set -f ..\.env

## Проверка локально

    pip install -r requirements.txt
    python watch_channels.py --dry-run

## Ручной запуск в облаке

    gh workflow run watch-channels
